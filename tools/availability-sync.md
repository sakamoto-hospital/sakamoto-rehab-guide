# 空き状況シート → サイト自動反映（Google スプレッドシート + Apps Script）

スプレッドシートの数字を書き換えると、サイトの空き状況が自動で切り替わる仕組みです。

```
スプレッドシートを編集
      ↓ （Apps Script が1分ごとに確認）
GitHub の assets/availability.json を更新
      ↓ （GitHub Pages が再公開：30〜60秒）
サイトが自動で読み込み（60秒ごと）→ 表示が切り替わる
```

実際に切り替わるまでの目安は **1〜3分** です。

---

## 1. スプレッドシートに Apps Script を入れる

1. Google ドライブの **「リハプラス さかもと 空き状況」**（旧名のときに作ったシート。名前はそのままで動きます）を開きます（作成済み。定員・曜日・クールの表が入っています）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初から入っているコードをすべて消し、[`tools/availability-sync.gs`](availability-sync.gs) の中身を貼り付けて保存します。
   コピー元：`https://raw.githubusercontent.com/sakamoto-hospital/sakamoto-rehab-guide/main/tools/availability-sync.gs`
   （全選択 → コピー → Apps Script に貼り付け）

> シート名は「空き状況」でなくても動きます（見つからない場合は先頭のシートを読みます）。

## 2. GitHub のトークンを作る

1. GitHub → 右上のアイコン → **Settings** → 一番下の **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. 次のように設定します。
   - **Repository access**：Only select repositories → `sakamoto-hospital/sakamoto-rehab-guide`
   - **Permissions → Repository permissions → Contents**：**Read and write**
   - **Expiration（有効期限）**：1年など。期限が切れると自動反映が止まるので、カレンダーに入れておくと安心です。
4. 表示されたトークン（`github_pat_…`）をコピーします。**この画面を閉じると二度と見られません。**

> トークンはこのリポジトリのファイルを書き換えられる鍵です。メールやチャットに貼らず、Apps Script の中だけに保管してください。

## 3. トークンを Apps Script に登録する

1. Apps Script の左メニュー **⚙ プロジェクトの設定** を開きます。
2. 下の方の **スクリプト プロパティ → プロパティを追加**
   - プロパティ：`GITHUB_TOKEN`
   - 値：コピーしたトークン
3. **スクリプト プロパティを保存** を押します。

## 4. 動かす

1. スプレッドシートを開き直すと、メニューに **「空き状況」** が増えています。
2. **空き状況 → 接続テスト**
   初回は権限の確認画面が出ます（「詳細」→「安全ではないページに移動」→ 許可）。許可のあと、もう一度実行してください。
3. 「GitHub に接続できました」「シートの形式も問題ありません」と出れば OK です。
4. **空き状況 → 自動反映をオンにする** … これで完了です。

## ふだんの使い方

シートの数字を書き換えるだけです。

| 書き方 | サイトの表示 |
| --- | --- |
| `8`（数字） | 空きあり　8/8 |
| `1` | 空きあり　1/8 |
| `0` / `満` / `×` | 受付調整中（押せなくなります） |
| 空欄 | 定員いっぱい空き |

- **B1 の「1クールの定員」** を変えると、8名以外にもできます。
- すぐ反映したいときは **空き状況 → 今すぐサイトに反映**。
- 同じ内容のときは GitHub に書き込まないので、無駄な更新履歴は残りません。

## 曜日やクールを増やしたいとき

- **曜日**：A列に行を足すだけです（サイト側は `availability.json` の `days` をそのまま読みます）。
- **クール**：見出し行に `⑤…` の列を足すと数字は保存されますが、サイトの時間帯の表示は `index.html` 側にも追記が必要です。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「GITHUB_TOKEN が未設定です」 | 手順3のプロパティ名が `GITHUB_TOKEN` になっているか |
| 「GitHub への書き込みに失敗しました（401 / 403）」 | トークンの期限切れ、または Contents が Read and write になっているか |
| 「①〜④のクール見出しが見つかりません」 | 見出し行に `①` などの丸数字が入っているか |
| サイトが変わらない | 3分ほど待つ／ブラウザを再読み込み／GitHub 上の `assets/availability.json` が更新されているか |

Apps Script の **実行数**（左メニューの時計アイコン）を開くと、失敗したときのエラー内容が確認できます。

## スプレッドシートを使わない場合

GitHub 上で `assets/availability.json` を直接編集しても同じことができます。数字を書き換えて Commit すれば、1〜2分でサイトに反映されます。
